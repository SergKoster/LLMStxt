# Сайты для проверки сервиса

Список, чтобы тестировать генерацию и сравнивать результат. Проверено 2026-11-11 запросами
с User-Agent `llms-generator/0.3.2` и прогоном через `generate()`. Сайты меняются: если результат
разошёлся с таблицей, сначала проверьте сайт в браузере.

## 1. Есть свой llms.txt — сравнивать с нашим

своими инструментами, поэтому это ориентир по содержанию, а не точная копия.
