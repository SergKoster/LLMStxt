# Задание (пересказ `Задача llms.docx`)

**Тема:** веб-сервис для генерации llms.txt (MVP).
**Цель:** пользователь вводит URL сайта, сервис в фоне генерирует `llms.txt` и отдаёт на скачивание.

## Стек (строго)

Python 3.11+ · FastAPI · HTML + Vanilla JS · Docker · библиотека `llms-generator`.

## Что должно быть

**Фронт**
- Страница с полем ввода URL (с валидацией) и кнопкой «Сгенерировать».
- После нажатия — индикатор загрузки.
- Опрос `GET /status/{task_id}` каждые 3 секунды.

**API**
- `POST /generate` — принимает `{url}`, проверяет, что начинается с `http`, создаёт `task_id` (UUID),
  запускает фоновую задачу (`BackgroundTasks`), сразу возвращает `{task_id, status: "processing"}`.
- `GET /status/{task_id}`:
  - файл готов → `FileResponse` с `Content-Disposition: attachment; filename="llms.txt"`;
  - ещё нет → `{status: "processing"}`;
  - ошибка → `{status: "error"}` с текстом ошибки.

**Фоновая задача**
- `subprocess.run(["llms-gen", url, "--depth", "3", "--output", "/tmp/llms_outputs/{task_id}.txt"])`.

**Ограничения**
- Таймаут одной генерации — 180 секунд, потом ошибка.
- Глубина обхода — `--depth 3`.
- Удалять сгенерированные файлы старше 1 часа.

**Развёртывание**
- Запуск одной командой `docker-compose up`.

## Критерии приёмки

- [ ] Открываю сервис в браузере, ввожу URL (например `https://habr.com`), через минуту скачиваю
      валидный `llms.txt`.
- [ ] На несуществующий URL — понятная ошибка, а не 500.
- [ ] Docker-контейнер собирается и запускается без ошибок.
- [ ] В репозитории есть `README.md` с инструкцией по запуску.
